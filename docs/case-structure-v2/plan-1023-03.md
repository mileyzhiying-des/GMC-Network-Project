## 分段（每段 commit + 回归；每段新增 selftest R118a…）
- **P1 升级判断 + 页型 + tab（IN、KR）**：新增数据层 `isUpgraded(m)`（付了赴韩定金 / 有 ≥2 个子案件 / 有复诊子记录）、`flowStatusOf(m, kind)`（✓ 已结束 / ● 还有事）；IN `caseTabsHtml` / `caseTabContentHtml` 重写 tab 栏：未升级 = 一般案件页（面诊 tab = 面诊内容 + 选项目卡；本地项目 tab = 原本地管理），升级后 = 完整格式（面诊 / 赴韩 / 术后管理 / 复诊 / 子案件 / 项目汇总…）；拿掉 `flowTabHtml` 的「流程」tab（卡片搬回各自 tab）；KR `KR_CASE_TABS` 同步（项目 → 赴韩，拿掉我加的流程 tab，加术后管理 / 复诊）；页头 1：没有面诊不写「从 xx 面诊开始」、「进行中」写具体内容（小修 9）。
- **P2 术后管理独立（IN、KR）**：新写 `postcareTabHtml(m, side)`（共用渲染，读 `careUnits` + `careRows`），按钮沿用各自现有入口（IN 印尼行［预约］／［修改时间］／［操作完成］走 `todoCareBookOpen` / `openCareUse`，KR 韩国行［预约时间］走 `krCbOpen`；对方的行只读）；IN 项目卡和 KR 项目卡里的「术后管理」小 tab 拿掉（一行说明连到新 tab）；新「复诊」tab（每次复诊一个流程行，展开 = 原复诊评估卡）。
- **P3 IN 子案件页**：新页面 `in-subcase`（`openSubcase(mainId, key)`）：页头 + tab 到访｜今日项目｜结算｜附件｜Timeline；到访 = 当天来访目的 / 메타뷰 / 当天照片（读接待记录）；今日项目 = 当天的项目卡（本地项目选购 / 使用、印尼术后管理［操作完成］，沿用 `projectListTabHtml` / `holdingsUseHtml` / `openCareUse`）+ 当天推进的流程连结；结算 = 当天收的钱（`childMoneyOf`）；韩国那天对 IN 只读。旧的「子记录页」（带旧 tab 的接待页）被它取代。
- **P4 KR 子案件页（特别小心）**：KR 页面加子案件视图 `KR_CASE.sub = {key}`（`krShowCase(…, {sub})`）；页头状态卡搬到这页（［客人已到院］［客人已离院］沿用 `krArriveMain` / `krArriveSub` / `krEndBtn…`）；今日项目 = 那一天的到院卡（`krCaseCardHtml` 原样，包括 Step 1–4 评估 / 术前照片 / 增加项目 Modal / 待付款拦截 / 操作完成 / 客人已离院）；主案件「赴韩」tab 只留安排（项目卡 + 到院日期列表，点一行进子案件页）。所有 `core*` / `kr*` 操作函数不改，只换容器；回归盯 R22b R47a R57a R59b R61b R66b R67a R69a R73a R74a R76a R77b R78a R79a R80a R81a R82a R83a R84a R87a R92a CAL2 CAL5 CAL6 CAL8 CAL10 TDK1 TDK2。
- **P5 入口 + 列表进程**：日历块 / 今天来访 / 今天来访待办 → 子案件页；流程待办（面诊结果、复诊结果、韩国行程是否结束）→ 主案件对应 tab；术后管理过期 → 术后管理 tab；案件管理 / 客户详情 → 主案件（`caseGo` 加 `{tab, sub}` 参数）；列表「进程」按优先级只写一件（今天来访 > 等我处理 > 等对方处理 > 未预约 / 过期 > 已完成）+ 新栏「其他进行中」（`mainAttentionOf(m, side)`）。
- **P6 本地持有 + 没做完的项目**：`mainHoldOf` 拆「赴韩疗程持有」（回原主案件）和「本地持有」（回来用 → 新的独立案件 `c.boughtFrom = {caseId, caseNo}`，页头标「来自 A000xxx 购买」）；只做本地每天一个独立案件（到店弹窗不再把本地持有归到原主案件）；离店 / 离院时没做的项目 → 弹窗选原因 → 回「未预约」（术后管理行 `skipped` 退回、管理项目回未使用）；`visitSweep` 00:00 同样处理，第二天早上待办请室长确认；赴韩 ＞ 本地（同一天两件事都有算赴韩主案件那天的子案件）。

1. P1 页型切换要保证所有旧的 `switchCaseTab('kr' / 'consult' / 'localmgmt')` 调用点仍落在正确的 tab（待办 / 通知 / 测试里很多）——加 `normalizeCaseTab` 映射；
