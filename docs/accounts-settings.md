## 二（续）、三、登录与激活（已做）
- **登录**（`login.html`）：账号编号（不分大小写）+ 密码；待激活 → 提示去"首次激活"；已停用 → 提示联系老板；成功后登录信息存在 **sessionStorage**（`gmc_acct`，每个标签页各自登录、可以同时登不同账号），老板 → `owner.html`，其他 → `in.html`。
- **页面守卫**：`in.html` 只允许 manager/general，`owner.html` 只允许 owner（`guardPage()`）；没登录 → 登录页；角色不对 → 回自己的首页；账号在别的标签页被停用/重置后，本页收到同步通知也会回登录页。
- **首次激活**：账号编号 + 登记的手机号（须一致）→ 获取验证码（**演示：验证码直接显示在屏幕上**，5 分钟有效，可重新获取）→ 输入验证码 → 设置密码（≥6 位，输两遍）+ 姓名 + 职位 + **证件照**（均必填）→ 账号变"使用中"，写入账号历史和操作日志，自动登录。
- **忘记密码**：账号编号 + 手机号 → 验证码（同上）→ 新密码；写账号历史和操作日志；只适用于使用中的账号。
- **头像菜单**（右上角头像，IN 端和老板端都有）：个人设置（现在是只读"个人资料卡"，设置页第五部分做）/ 切换账号 / 退出登录。"切换账号"和"退出登录"只清当前标签页的登录信息。
- **演示用角色下拉已删除**（案例库、项目库页面右上角原来的"演示用：印尼室长/韩国室长"）；`DEMO_ROLE` 固定为 'in'，所以赴韩项目/赴韩案例的 KR 端编辑演示入口不再有（对应 CLAUDE.md 已知差距第 1 条：原型里不再演示 KR 室长维护）。
- **当前用户不再写死 Dewi**：`ME_NAME` = 登录账号的姓名；案件 Timeline 新记录的操作人、结算单下单人、附件上传人、对话消息发送人、视频通话名单、推播收件人判断（`shouldPushToMe`）、"早上好，XXX"、侧边栏、对话成员列表等都跟当前账号走（种子演示数据里的 Dewi 保留，`SEEDING`/`actingName()` 区分）。
