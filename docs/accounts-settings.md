## 六、账号管理（A6，2026-10-06 已做；Notion IN-SETT-01 第 3 节）
- 页面 `ADMIN_RENDER.accounts`（老板、管理者）：席位概览（基本 3 个 = 老板/管理者/一般室长各 1，不能退订；加购管理者、加购一般室长数量；待激活数量）+ 账号列表（账号 ID / 类型 / 当前使用人（证件照、姓名、职位）/ 席位 / 状态）；点一行 → 详情弹窗：使用人历史（`ACCOUNTS[].history`）+ 该账号的操作记录（`ACCOUNT_LOG` 里 `target` = 该账号）。
