## 1. 客户与案件
- **客户**是长期存在的记录，一个客户可以有很多案件；**持有项目、医美史**挂在客户层，不属于任何案件
- **案件** = 一次预约引出的一件事：同一天、同一次到店做的所有事都在同一个案件里；另一天来就重新预约、开新案件；同一客户可同时有多个进行中的案件
- **Case ID** 在预约时生成（英文+6位数字），一直用到结案；**不再有 Reservation ID**
- **面诊/赴韩案件**：走面诊流程的案件；**本地案件**：基础资料选"不面诊"的案件
- **关联**：只用于不同天的案件之间（复诊 / 术后管理 / 延续既往面诊），由室长在接待时操作，客人自助预约不涉及；关联只负责展示和权限，不影响状态和结局
- **客户详情页**：正在进行案件 / 持有项目 / 基础信息（可改；隐私协议只读）/ 医美史（案件记录 + 本院项目记录）/ Timeline，详见 IN-CLNT-01
- **客户列表**：状态和财务以该客户最近一次有操作的案件为准；未完成的案件在客户详情"正在进行案件"里全部列出

## 2. Timeline 与修正
- 客户级 Timeline 只记：建档、基础信息修改、案件开始、案件结案（进行中显示"进行中"）
- 案件级 Timeline 是另一份，记案件内的具体过程；只追加、不修改
- 格式：`阶段　内容　「操作人」　YYYY-MM-DD HH:MM`
- 室长修正客户原填字段（如医美史、已选院长）时，修正直接覆盖为定论，不做两版对比；谁改了什么由 Timeline 的"修正"条目留痕

## 3. 谁决定什么
| 事项 | 谁决定 |
|---|---|
| 是否需要面诊 | IN 室长与客户沟通后决定 |
| ~~面诊形式（视频 / 书面）~~ | 已废弃（2026-10-02）：面诊只有一种，院长看资料口述、KR 室长整理提交报告 |
| 是否需要赴韩施术 | 院长面诊后建议，客户自主决定是否愿意赴韩 |
| 赴韩项目可选范围 + 备注（含相冲项目） | KR 室长整理（院长口述），不需经过院长确认；范围外由 KR 室长在对话中补加 |
| 术后管理项目 | KR 室长写入可选范围；施术完成时确认（可修改）并标注进行时间；在韩国可补加 |
| ~~二次面诊收费 / 免费~~ | 已废弃（2026-10-02）：一个案件只面诊一次 |
| 面诊费免除 | IN 室长，必选原因 |
| 施术日期 | IN 室长选首选+备选日期（限KR开放日），KR 室长定具体时间；改期由 IN 室长操作（需与客人确认） |
| 赴韩项目完成 / 无法施术 / 已到医院 / 付清尾款 | KR 端标注（可逐个或批量），IN 只看结果 |
| 退款（退不退、退多少） | IN 室长手动决定，退款原因必填；系统不自动判断 |
| 到医院后取消项目 | 只有 KR 能发起（无法施术 / 更换项目） |
| 更换项目 | 在韩国发生由 KR 操作，在印尼发生由 IN 操作 |

## 4. 钱
- **面诊费**与**赴韩定金**是两笔独立收费；只面诊不赴韩的客户只付面诊费
- **面诊费免除**：必选原因（复诊 / 延续既往面诊 / 其他）；面诊取消时面诊费由当地自行处理，系统只记录状态
- **结算结构**：赴韩项目收定金（印尼）+ 尾款（到韩国付，KR 标记）；本地项目收全款；一起结算时结算单也要分开列（赴韩韩元 / 本地印尼盾）
- **本地项目**可打折（IN 室长填折扣，可写备注），结算单同时显示原价和折后价
- **项目快照**：项目被选进案件时复制当时的ID、名称、价格、币种；之后项目库改价/改名/停用都不影响已选项目；结算后不可更改
- **系统只记录收没收款，不处理实际收款**
- **退款**：IN 室长手动填金额（可为0）+ 原因必填；赴韩项目在结算单"取消项目"操作；本地项目在客户详情"持有项目"按批次退款（2026-10-02 改：只要批次还有剩余次数——未使用、部分使用——就可退，退后该批次作废、剩余归零；已用完的不能退；~~原规则只有未使用的批次可退~~ 已废弃）；本地管理里的"管理取消"不是退款，只归还次数
- **KR 代收**：在韩国补加的术后管理项目由 KR 当场代收，标"KR代收"，在印尼不再付款
- **财务结果**是案件的独立字段（无收入 / 仅面诊费 / 有项目收入 / 全额退款），不影响案件结局
- 韩国施术没有次卡

## 5. 韩国侧（KR）能看到什么
- 不面诊的案件：看不到；点"增加面诊"后可见
- 看到过的案件之后被取消：仍可见，显示"已取消"
- 意向项目、预算、关联之前案件带出的报告、上传附件：可见
- 结算备注：赴韩项目卡备注、整体备注可见；本地项目卡备注不可见
- 使用了术后管理项目的本地案件：通过关联只读可见，一直跟踪到这批术后管理项目用完

## 附：Glossary 术语（节选，"一个词只有一个定义"）
- **"预约"一词的5种用法**：预约占位（日历15分钟临时色块，还不算案件）/ 预约来访（客户提交或室长代约后的到店预约，生成Case ID，状态待访问）/ 面诊预约（案件大状态，选择面诊后、等KR确认面诊时间之前，含待缴费）/ 施术预约（案件大状态，付款后选日期、等KR确认施术时间）/ 预约第二次面诊时间（二次面诊子流程里的一步，不改主状态）
- **"取消"**：取消占位（色块消失，不产生案件）/ 取消预约（案件→已取消·预约取消，终态）/ 取消接待（接待中回到待访问，防误点）/ 面诊取消（面诊费→已取消；不做本地则案件→已取消·面诊取消）/ 取消项目（赴韩项目→已取消，附退款金额+原因）/ 管理取消（本地项目→已取消，次数归还，不是退款）/ 持有批次退款（整批→已取消，不影响任何案件结局）；原则：**东西被取消，钱另外记**
- **"完成"与"结案"**：施术完成=KR对赴韩项目的标注（逐个或批量）；管理完成=IN对本地管理项目的标注；结案/结局=整个案件的终态，只有已结案/仅出报告/已取消，由系统按"客人得到了什么"推算
- **面诊**：只有一种——院长看资料口述，KR室长整理提交报告，院长不参与视频；~~二次面诊~~ 已废弃（一个案件只面诊一次）；**增加面诊**：不面诊的案件后来要面诊的入口；**报告**：由KR室长上传，"已出报告"是Timeline事件；**可选范围**：KR室长随报告给出的赴韩项目+术后管理项目范围；**室长商谈**：出报告后邀请上传报告的KR室长视频，次数不限
- **项目**：赴韩项目（只能从可选范围选，付定金）/ 本地项目（买完转持有）/ 术后管理项目（本地项目的分类，也是持有项目，置顶）/ 持有项目与批次（每次购买一个批次，先扣最早批次，只能用在同一个项目上）/ 意向项目（基础资料里记录，KR可见，不等于已选项目）
- **显示**：大状态/小状态；案件列表tab是UI分组；并行模块（面诊/赴韩案件里的本地管理，只显示小标签"本地管理进行中"）；状态正常/非正常（任一项目带黄色小标签或已更换即非正常）
- **角色**：IN室长（系统主要使用者）/ KR室长（确认面诊/施术时间、上传报告、整理可选范围、标注施术进度）/ 院长（出席视频面诊，名单由KR端维护）/ 客人

## 工作台与日历（IN-DASH-01 · 2026-10-02 修订，待写入 Notion）
- **全原型只有一份案件数据**（含预约、占位、施术时间、操作人记录）：日历、今日区块、案件列表、客户列表、客户详情"正在进行案件"、预约历史记录都从这份数据算；在案件里推进状态后其他页面同步
- **日历事件类型只有三种**：预约来访 / 预约占位 / 赴韩施术；删除"视频沟通""术后管理""其他"类型
- 预约来访事件块**两行**：第一行客人名字（粗体）、第二行来访目的；不再写"预约来访"文字，类型靠颜色和左边色条区分（预约占位、赴韩施术同样名字放第一行）；来访目的：面诊商谈 / 皮肤商谈 / 术后管理 / 复诊 / 皮肤管理（代约、自助预约都能选，不影响流程）；接待时目的是术后管理 / 复诊 → 基础资料提示"要不要关联之前的案件"
- 同时段多个预约并排；**背景不整片灰**，只有已过去/已结束的事件块灰色；过了预约时间但 30 分钟内还没到访的预约来访保持亮色并显示倒计时；时间格 hover：已过去、不能约的时段整格灰色，可以预约的时段整格粉色，点击新增预约；现在的时间点用彩色外框标出当前时段；月视图和周视图一样高，都撑满画面（扣掉问候和今日 OFF 行）
- **双时间轴**：IN（诊所）时间下面一行小字显示 KR 时间；诊所时区放在设定里（默认 WIB，可切 WITA / WIT），时差不写死；右上角天气显示诊所所在城市（演示：雅加达）
- **今日 OFF 一行**（2026-10-02 深夜取代"今日区块"，今日行程列表已删除）："早上好"下面直接一行"今日 OFF："+院长、KR 室长、IN 室长的名字，没人 OFF 不显示；通话进行中时通话卡片在这一行下面、日历上方
- **固定栏 memo**：周视图 9:00 上面每天一格，显示当天 OFF 和 memo；新增 memo：选日期、类型（备忘 / OFF）、公开 / 私人，类型 = OFF 时固定公开，显示作者；IN 室长的 OFF 就从这里来；KR 院长 / KR 室长的 OFF 用演示数据代替（KR 端功能）
- **KR 医院日程（只读）**：日历可切换"本院日程 / KR 医院日程"；显示 KR 室长登记的日程、院长日程（下拉切换院长）、KR 开放的施术日期；有空 = 白色，已排的事 = 浅灰块，每件事一个独立的块（中间留缝隙）
