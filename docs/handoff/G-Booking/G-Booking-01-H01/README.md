页面背景（棕榈叶光影图）**不是顶栏的一部分**，是 G-Booking-01 整页背景；Notion 把它写在本元素的「内容」里，⚠ 建议移到页面 G-Booking-01 的说明。快照里为了好看也放了背景图。

## 每个东西
| 东西 | 显示什么 | 数据从哪来 | 何时显示 |
|---|---|---|---|
| 诊所名 | 当前诊所的名称 | 诊所设定里的诊所名（诊所 id 来自网址参数 `?clinic=Cx`，原型不带参数默认 C1）；读不到时用演示值「GMC 合作诊所（雅加达）」 | 只在首页显示（G-Booking-01） |
| 语言切换 | 两个按钮 `Bahasa Indonesia`、`中文`（按钮文字两种语言下都一样，不翻译）；当前语言那个是「选中」样式 | 当前语言 = 网址 `?lang=id\|zh` > 浏览器里上次选的（localStorage 键 `gmc_book_lang`）> 默认印尼文 `id` | 一直显示 |

## 交互
- 点语言按钮：立刻切换整套预约页的文字（不换页、不刷新）；把选择记在浏览器里，下次打开沿用；已填的资料不受影响。
- 诊所名：不能点。
- 没有跳转（留在当前页）。

## 样式要点（取自浏览器里算出来的实际值，完整 CSS 见 snapshot.html / base.css）
- 外层：最大宽 480px 居中，左右内距 16px；顶栏 flex，两端对齐，顶部对齐（`align-items:flex-start`），不换行。
- 诊所名：14px，粗体 700，颜色 #3B2A1E，行高 1.3。
- 语言胶囊：圆角 999px；底色 rgba(255,255,255,.7)；边框 1px rgba(255,255,255,.9)；背景模糊 6px；每个按钮内距 6px 9px，字号 12px。
- 选中按钮：底色 #F6E9DE，文字 #9A6A4B，粗体 700。未选中：文字 #3A342F，常规字重，无底色。
- 字体：Pretendard，找不到用 "Noto Sans SC" 等系统字体。⚠ 截图机器上没装 Pretendard，实际显示的是回退字体，字形和线上会有细微差别。

## 其他页面里的同一个顶栏（⚠ 与首页不同，Notion 没记录）
- 非首页（步骤 1～9、查看我的预约…）：左边不是诊所名，而是固定文字 `GMC Network` + 一行小字（印尼文 `Reservasi online` / 中文 `在线预约`）；语言胶囊是默认样式（白底 + 灰边框，选中 = 深色底白字）。
- 本元素只描述首页版。

## 原型专用、正式版不要做的部分
- 演示诊所名的写死兜底值（读不到诊所时用「GMC 合作诊所（雅加达）」）。
- 「新样式」颜色映射（`dstyle.js` 在运行时把写死色值换成设计变量）——快照里已经直接写成最终值。
- 无参数入口与 `?ph=` / `?walkin=` / `?view=` 等入口：只影响是否进首页，与顶栏本身无关。
